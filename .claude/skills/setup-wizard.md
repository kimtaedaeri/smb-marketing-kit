# 셋업 마법사

비개발자 사장님이 대화만으로 이 키트를 셋업하도록 단계별로 안내한다.
한 번에 한 단계씩, 사장님 답변을 기다리며 진행한다. 전문용어는 쉽게 풀어 쓴다.

## 순서

1. **브랜드 보이스 인터뷰** — `brand_voice.template.md` 항목을 대화로 하나씩 물어
   채운 뒤 `brand_voice.md` 로 저장한다. 실제 사장님이 쓴 글 예시를 꼭 받아 문체를 학습한다.

2. **정책 설정** — `policy.example.yaml` 을 바탕으로 게시 플랫폼·주간 스케줄·
   일일 상한을 정해 `policy.yaml` 로 저장한다. 상한·승인 게이트의 이유(계정 정지 방어)를 설명한다.

3. **커넥터 연결** — `connectors.md` 를 따라 Higgsfield(생성)·Blotato(배포)를 등록하고,
   `naver-marketing-mcp` 를 로컬 설치하도록 안내한다. 각 단계 후 연결을 확인한다.

4. **첫 콘텐츠 미리보기(게시 X)** — 상품 하나를 골라 Higgsfield 로 카루셀 이미지를 만들고,
   플랫폼별 카피(인스타=해시태그5+에너지 캡션 / 링크드인=~1,400자 / 네이버블로그=정보성)를
   `brand_voice.md` 문체로 생성한다. **approve=False 로 초안만** 보여주고 승인을 받는다.

5. **루틴 제안** — "매주 월 8시 7개 생성·예약" 같은 루틴을 원하면 스케줄 설정을 안내한다.
   단, 네이버는 기본 승인 게이트를 유지한다.

## 안전 규칙 (항상)
- 네이버 게시는 항상 초안 미리보기 → 사장님 승인 후 게시.
- 크리덴셜은 로컬 키체인만. 절대 화면에 비밀번호를 요구/노출하지 않는다.
- 실제 사업·실제 계정 마케팅 용도로만 안내한다.
