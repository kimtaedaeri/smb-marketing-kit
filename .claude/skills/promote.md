# 원클릭 홍보

사장님이 상품 설명(+이미지)만 주면, 검증된 파이프라인 전체를 한 번에 돈다.
**항상 미리보기→승인 후에만 게시한다.** 실계정에 올라가므로 신중히.

## 입력
- 상품/공지 설명 (필수)
- 이미지 파일 경로 또는 URL (선택 — 인스타는 이미지 필수)
- 대상 채널 (기본: 네이버 블로그·인스타·스레드. `policy.yaml` content.platforms 참고)

## 절차

1. **브랜드 보이스 로드** — `brand_voice.md` 있으면 그 말투로. 없으면 상품 톤에 맞춰(예: 복싱앱=에너지) 쓰되, 사실만.

2. **채널별 재가공** — 하나의 소재를 채널 성격대로 **다시 쓴다**:
   - 인스타: 후킹 첫 줄 + 이모지 + 해시태그 5개 (에너지)
   - 스레드: 짧고 대화체 (≤500자)
   - 네이버 블로그: 정보성, SEO 제목 + **글·이미지 번갈아 배치(blocks)**
   각 초안을 `validate_channel_post` 로 검증(길이·해시태그·이미지). 실패 시 고쳐서 다시.

3. **이미지 준비** — 로컬 이미지는 `prepare_images`(또는 instagram_publish 가 자동)로 **4:5 변환·공개 호스팅**.
   - 인스타: 여러 장이면 캐러셀. 폰 스크린샷은 반드시 변환.
   - 네이버: 원본 로컬 이미지를 blocks 에 넣어 글 사이사이 배치.

4. **미리보기 → 승인 (필수 게이트)** — 채널별 최종 카피·이미지 배치를 사장님께 한 번에 보여주고,
   **"이대로 올릴까요?"** 승인받는다. 수정 요청 있으면 반영 후 다시.

5. **동시 게시** — 승인되면:
   - `instagram_publish(image_urls, caption, approve=True)` (로컬 경로면 자동 처리)
   - `threads_publish(text, image_urls?, approve=True)`
   - `naver_blog_publish(title, blocks=[...], tags, private=False, approve=True)`
   각 채널 결과(게시 성공/URL)를 요약 보고. 실패 채널은 원인과 함께.

## 안전·품질
- 사실·수치는 소스와 일치(과장·왜곡 금지).
- 네이버는 하루 소량·페이싱(정지 리스크). 세션 만료 시 `connect_naver` 로 재로그인 안내.
- 인스타·스레드 미연결 시: 재가공·미리보기까지 하고 `connect_meta`/`set_instagram_token`·`set_threads_token` 안내.
- 완전 자동(무인)은 사장님이 명시적으로 요청할 때만. 기본은 승인 게이트.
