# 인스타·페북 연결 (초보자용, 손잡고)

**원칙: 사장님은 겁먹지 않게. 한 번에 한 가지만. 어려운 말 금지. 항상 다음 한 걸음만 알려준다.**

## 진행

1. **먼저 상태 점검** — `meta_preflight` 를 호출한다. 결과의 `message`/`how` 를 사장님 말로 그대로 전한다.
   - `ready_to_connect` → 2번으로.
   - `page_not_linked` → 4번(인스타-페이지 연결) 안내로.
   - `need_setup` → 아직 준비 전. 원클릭(META_BROKER_URL)이 있으면 그걸, 없으면 "지금은 테스트 준비 중"이라고 안내.
   - `connected` → 이미 됨. 바로 게시 가능하다고 알림.

2. **연결 실행** — `connect_meta` 를 호출한다. "잠시 후 로그인 창이 떠요. 페이스북 로그인하고 '허용'만 누르시면 돼요"라고 미리 안내.

3. **결과를 사장님 말로** — 반환된 `message`/`how` 를 그대로 전달한다.
   - `connected` → "연결 끝났어요! 이제 인스타에 올릴 수 있어요." (게시해볼지 물어본다)
   - `page_not_linked` → 4번으로.
   - `no_page` → 5번(페이지 만들기)으로.

4. **인스타를 페이스북 페이지에 연결 (가장 흔한 막힘)**
   아주 쉽게, 순서대로:
   - 인스타 앱 열기 → 내 프로필 → 오른쪽 위 ☰ → **설정 및 개인정보**
   - **비즈니스 도구 및 관리자 도구**(또는 크리에이터 도구) → **Facebook 연결**
   - 페이지를 고르라고 나오면 선택 (없으면 5번 먼저)
   - 다 되면 "됐어요"라고 말해달라 → 다시 1번(점검)부터.

5. **페이스북 페이지가 없으면 (무료로 만들기)**
   - 페이스북 앱/웹 → 메뉴 → **페이지** → **새 페이지 만들기**
   - 가게 이름 + 카테고리만 넣고 만들기 → 4번으로.

## 말투 규칙
- "API·토큰·OAuth" 같은 단어 쓰지 않는다. "연결", "로그인", "허용"처럼 쉬운 말만.
- 사장님이 막히면 지금 화면에 뭐가 보이는지 물어보고, 딱 다음 한 걸음만 짚어준다.
- 안 되면 "인스타를 비즈니스 계정으로 바꾸면 확실해요(무료)"를 마지막 카드로 제시.
