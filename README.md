# SMB Marketing Kit · 소상공인 마케팅 키트

> **Claude Desktop / Code에 설치**해, **대화만으로** 네이버 검색광고 입찰과
> 네이버 블로그·인스타·페북 콘텐츠 생성·재가공·배포·성과 확인을 자동화하는 셀프서브 MCP.

**해자 = 네이버.** Blotato·Buffer·Hootsuite 같은 글로벌 도구는 아무도 네이버를 지원하지 않고,
국내 툴은 파편화된 블로그 자동화뿐입니다. 이 키트는 **네이버 블로그(자동 게시) + 네이버 파워링크(공식 API)
+ Meta(공식 무료 API) + AI 재가공**을 하나로 묶습니다.

## 무엇을 하나

| 영역 | 구현 |
| --- | --- |
| **브랜드 보이스** | 인터뷰형 추출 → 사장님 말투로 모든 카피 생성 |
| **네이버 블로그** | 자동 게시(제목·본문·이미지·태그·공개범위) · 로그인/세션 · **수동 어시스트 폴백** |
| **채널 재가공** | 하나의 소재를 인스타·링크드인·X·스레드·페북 규격으로 재가공·검증 |
| **Meta 게시** | 인스타·페북·스레드 (Meta **무료 공식 API** — Blotato 불필요) |
| **원클릭 연결** | 브로커가 OAuth 대행 → 사용자는 로그인만(앱 시크릿 노출 없음) |
| **무인화** | 예약 발행 큐 · 러너(launchd/cron) · 주간 리포트 · 플랫폼 하드캡 |
| **퍼포먼스** | 네이버 파워링크 입찰(공식 API · 병행 트랙) |

## 아키텍처

```
Claude Desktop/Code            = 두뇌 + 브랜드보이스 + 스킬(셋업·연결·재가공)
   └── naver-marketing-mcp     = 손발(로컬): 네이버 발행 · Meta 게시 · 재가공 ·
                                  파워링크 · 예약/러너 · 안전장치 · 로그
   ├── meta-connect-service    = 원클릭 OAuth 대행(앱 시크릿은 서버만, 토큰 즉시 폐기)
   └── [커넥터] 이미지 생성      = Higgsfield 등 (채널 비율에 맞춰 생성)
```

크리덴셜은 로컬을 벗어나지 않습니다. 로컬·자기 IP 실행이 네이버 자동화의 정지 리스크를 구조적으로 낮춥니다.

## 안전 원칙

- **기본은 반자동**: 생성 → 미리보기 → **승인** → 게시. 전자동은 예약(=승인) 또는 명시적 opt-in.
- **인스타는 공식 API만** — 브라우저 자동화 안 함(ToS·탐지). 네이버 블로그만 로컬 브라우저.
- **페이싱·상한**: 일일 상한 + 플랫폼 하드캡(인스타 50/일·스레드 250/일) + 랜덤 지연. 불안하면 `naver.mode: assist`.
- **크리덴셜 로컬만**: 세션·`.env` 커밋 금지. 본인 계정·본인 사업만.
