# 무인 스케줄러 배포

예약 발행(`schedule_post`)을 실제로 자동 실행하려면, 러너(`python -m naver_marketing_mcp.runner`)를
주기적으로 돌려야 합니다. 러너는 예약 시각이 지난 항목을 골라 발행하고 일일 상한을 강제합니다.

> **채널별 실행 위치**
> - **네이버 블로그**: 브라우저 + 로컬 세션이 필요 → **로컬(launchd)** 에서만 동작.
> - **인스타·페북(Meta API)**: 서버에서도 가능 → 로컬 또는 **GitHub Actions** 둘 다 OK.

## A. 로컬 (macOS launchd) — 네이버 포함 전체

`~/Library/LaunchAgents/com.smbkit.runner.plist` 로 저장(경로 2곳 수정):

```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0"><dict>
  <key>Label</key><string>com.smbkit.runner</string>
  <key>ProgramArguments</key>
  <array>
    <string>/ABS/PATH/naver-marketing-mcp/.venv/bin/python</string>
    <string>-m</string><string>naver_marketing_mcp.runner</string>
  </array>
  <key>WorkingDirectory</key><string>/ABS/PATH/naver-marketing-mcp</string>
  <key>StartInterval</key><integer>3600</integer>   <!-- 1시간마다 -->
  <key>StandardOutPath</key><string>/tmp/smbkit-runner.log</string>
  <key>StandardErrorPath</key><string>/tmp/smbkit-runner.err</string>
</dict></plist>
```

등록: `launchctl load ~/Library/LaunchAgents/com.smbkit.runner.plist`
해제: `launchctl unload ~/Library/LaunchAgents/com.smbkit.runner.plist`

## B. GitHub Actions — Meta(인스타·페북) 전용

`.github/workflows/runner.yml` (네이버는 여기서 동작하지 않음):

```yaml
name: scheduled-runner
on:
  schedule: [{ cron: "0 * * * *" }]   # 매시 정각(UTC)
  workflow_dispatch:
jobs:
  run:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with: { python-version: "3.12" }
      - run: pip install -e ./naver-marketing-mcp
      - run: python -m naver_marketing_mcp.runner
        env:
          META_BROKER_URL: ${{ secrets.META_BROKER_URL }}
```

## 안전
- 러너도 `policy.yaml` 의 일일 상한 + 플랫폼 하드캡(인스타 50/일·스레드 250/일·네이버 보수적)을 강제합니다.
- 예약 = 사용자 승인으로 간주하고 발행합니다. 무인 전에 반드시 미리보기·승인 흐름으로 큐를 채우세요.
