# Meta(인스타그램·페이스북) 무료 연결

Blotato 같은 유료 서비스 없이 **Meta 공식 API로 무료** 게시합니다. 두 가지 모드가 있습니다:

| 모드 | 사용자가 할 일 | 언제 |
| --- | --- | --- |
| **원클릭(브로커)** | `.env` 에 `META_BROKER_URL` 만 넣고 로그인 | 앱 심사 통과 후(외부 사용자용). `docs/META_APP_REVIEW.md` |
| **개발자 모드** | 앱 1회 생성 + 로그인 (아래) | 지금 본인/테스터 계정으로 바로 검증 |

> 원클릭 모드는 `META_BROKER_URL` 만 있으면 아래 A/B 없이 `connect_meta` 로 로그인만 하면 됩니다.
> 아래는 **개발자 모드**(지금 바로 본인 계정 검증용) 안내입니다.

---

## (개발자 모드) 자동화가 안 되는 건 딱 하나: 앱 1번 만들기(아래 A). 그 뒤는 전부 자동입니다.

## 사전 준비 (계정)
- 인스타그램을 **비즈니스/크리에이터 계정**으로 전환
- **페이스북 페이지** 1개 + 그 페이지에 위 인스타 계정 연결
  (인스타 앱 → 설정 → 계정 → 연결된 페이지, 또는 페이지 설정에서 연결)

## A. 앱 1번 만들기 (약 3분, 최초 1회만) — 사장님이 하는 유일한 수동 단계

1. https://developers.facebook.com → 로그인 → **내 앱 → 앱 만들기**
2. 유형 **"비즈니스"** 선택 → 앱 이름 입력 → 생성
3. 좌측 **제품 추가**에서 **Instagram**(그래프 API) 추가
4. **앱 설정 → 기본 설정**에서 **앱 ID**와 **앱 시크릿** 복사
5. **Facebook 로그인 → 설정 → 유효한 OAuth 리디렉션 URI**에
   `http://localhost:8765/callback` 추가 후 저장
6. **앱 역할 → 역할**에서 본인 계정이 관리자인지 확인
   (개발 모드에선 앱에 등록된 계정만 게시 가능 — 본인 계정은 OK.
   외부 고객까지 열려면 나중에 앱 심사가 필요합니다.)

## B. 키 저장 (.env)

키트 루트에 `.env` 파일을 만들고(이미 있으면 추가), 아래를 넣습니다. (`.env`는 커밋 안 됨)

```
META_APP_ID=복사한_앱_ID
META_APP_SECRET=복사한_앱_시크릿
```

## C. 연결 — 여기서부터 전부 자동, 사장님은 로그인만

Claude에게:
```
connect_meta 실행해줘
```
→ 브라우저 창이 뜨면 **페이스북 로그인 + 권한 동의**만 하시면 됩니다.
그 다음(코드↔토큰 교환, 60일 장기 토큰, 페이지 토큰, 인스타 계정 ID 조회·저장)은 자동입니다.

성공하면 `ig_user_id`가 잡히고, 이후 `instagram_publish` / `facebook_publish` 로 게시할 수 있습니다.

## 참고
- 인스타 게시 이미지는 **공개 URL**이어야 합니다(Graph API 제약). Higgsfield 생성 이미지는 URL로 오므로 그대로 사용 가능.
- 토큰은 60일마다 갱신이 필요합니다(추후 자동 갱신 예정).
- 스레드(Threads)는 별도 앱/권한이라 다음 단계에서 추가합니다.
