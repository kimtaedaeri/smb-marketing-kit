# Meta(인스타그램·페이스북) 무료 연결

Blotato 같은 유료 서비스 없이 **Meta 공식 API로 무료** 게시합니다. 두 가지 모드가 있습니다:

| 모드 | 사용자가 할 일 | 언제 |
| --- | --- | --- |
| **원클릭(브로커)** | `.env` 에 `META_BROKER_URL` 만 넣고 로그인 | 앱 심사 통과 후(외부 사용자용). `docs/META_APP_REVIEW.md` |
| **개발자 모드** | 앱 1회 생성 + 로그인 (아래) | 지금 본인/테스터 계정으로 바로 검증 |

> 원클릭 모드는 `META_BROKER_URL` 만 있으면 아래 A/B 없이 `connect_meta` 로 로그인만 하면 됩니다.
> 아래는 **개발자 모드**(지금 바로 본인 계정 검증용) 안내입니다.

---

## (개발자 모드) Instagram Login 방식 — 페이스북 페이지 불필요

2025년 "Instagram API with Instagram Login" 을 쓰면 **페이스북 페이지 없이** 인스타
프로페셔널(비즈니스/크리에이터) 계정에 바로 게시할 수 있습니다. 사장님이 하는 건 앱 1번 만들기 + 로그인뿐.

### 사전 준비
- 인스타그램을 **프로페셔널(비즈니스 또는 크리에이터)** 계정으로 전환 (무료·즉시)

### A. 앱 만들기 (약 3분, 1회)
1. https://developers.facebook.com → 로그인 → **내 앱 → 앱 만들기**
2. 사용 사례에서 **"Instagram"** 선택(없으면 "기타" → 유형 "비즈니스") → 앱 이름 → 생성
3. 좌측 **제품 → Instagram → 설정**(Instagram API 설정)으로 이동
4. **"Instagram 비즈니스 로그인 설정"** 에서:
   - **유효한 OAuth 리디렉션 URI** 에 `http://localhost:8765/callback` 추가
   - **Instagram 앱 ID** 와 **Instagram 앱 시크릿** 복사
5. **역할 → 테스터**에 본인 인스타 계정을 추가하고, 인스타 앱 알림에서 **초대 수락**
   (개발 모드에선 테스터로 등록된 계정만 게시 가능)

### B. 키 저장 (.env — 커밋 안 됨)
키트 루트 `.env` 에:
```
META_IG_APP_ID=복사한_Instagram_앱_ID
META_IG_APP_SECRET=복사한_Instagram_앱_시크릿
```

### C. 연결 — 사장님은 로그인만
Claude에게: `connect_meta 실행해줘`
→ 인스타 로그인 창이 뜨면 **로그인 + 권한 허용**만. 그 뒤(토큰 교환·60일 장기 토큰·계정 ID)는 자동.
성공하면 `ig_user_id` 가 잡히고 `instagram_publish` 로 게시할 수 있습니다.

## 참고
- 인스타 게시 이미지는 **공개 URL**이어야 합니다. Higgsfield 생성 이미지는 URL로 오므로 그대로 사용.
- 토큰은 60일마다 갱신(추후 자동 갱신).
- 페이스북 페이지 게시(`facebook_publish`)는 페이지를 쓰는 경우에만 별도 설정(구 방식).
- 스레드(Threads)는 별도 권한이라 다음 단계에서 추가합니다.
