# Meta 앱 심사 플레이북 (원클릭 연결을 위한 1회 작업)

목표: **모든 사용자가 "인스타 연결" 버튼으로 로그인만** 하면 되도록, 우리 앱을 App Review 통과시킨다.
이 문서의 문구·스크립트는 **그대로 복붙·제출**하면 되도록 준비했다. (kimtaedaeri 1회 진행)

> 심사 없이도 **본인·지정 테스터 계정**은 개발 모드로 바로 게시 가능(docs/META_SETUP.md).
> 심사는 "외부 고객까지 원클릭으로 열 때" 필요하다.

## 0. 준비 체크리스트
- [ ] 브로커 서버 배포 완료(`meta-connect-service/`) → 공개 URL 확보
- [ ] Meta 앱 생성(유형: 비즈니스) + Instagram/Facebook 로그인 제품 추가
- [ ] 앱에 아래 URL 등록:
  - OAuth 리디렉션: `{BROKER}/connect/callback`
  - 개인정보처리방침: `{BROKER}/privacy`
  - 데이터 삭제 콜백: `{BROKER}/data-deletion`
  - 연결 해제 콜백: `{BROKER}/deauthorize`
- [ ] 앱 아이콘(1024px), 카테고리 설정
- [ ] 테스트용 인스타 **비즈니스 계정** + 연결된 페이스북 페이지

## 1. 비즈니스 인증 (Business Verification)
`instagram_content_publish` 등 고급 액세스는 **비즈니스 인증**이 전제인 경우가 많다.
- 앱 대시보드 → **비즈니스 인증** 진입
- 사업자 정보(상호·주소·대표번호) 입력, 필요 시 서류(사업자등록증 등) 제출
- 도메인/웹사이트 확인(브로커 도메인 사용 가능)
> 이 단계는 법인/개인사업자 서류가 필요 — kimtaedaeri 만 가능.

## 2. 요청할 권한(Advanced Access)
| 권한 | 이유(제출 문구에 사용) |
| --- | --- |
| `instagram_content_publish` | 사용자가 자신의 IG 비즈니스 계정에 게시물을 발행 |
| `instagram_basic` | 사용자의 IG 계정/미디어 기본 정보 조회 |
| `pages_show_list` | 사용자의 페이스북 페이지 목록 조회(IG 연결 확인) |
| `pages_read_engagement` | 페이지-IG 연결 및 기본 정보 조회 |
| `pages_manage_posts` | 사용자가 자신의 페이스북 페이지에 게시 |
| `business_management` | 페이지/IG 자산 접근 관리 |

## 3. 제출용 앱 설명 (복붙)

> **앱 이름**: (예) SMB Marketing Kit Connect
>
> **앱 설명**: 소상공인이 자신의 인스타그램 비즈니스 계정과 페이스북 페이지에 자신의 마케팅
> 콘텐츠(이미지·캡션)를 직접 발행하도록 돕는 도구입니다. 사용자는 Meta 로그인으로 본인 계정을
> 연결하고, 본인이 작성·승인한 게시물만 발행합니다. 타인 데이터 수집·광고·분석 목적 사용은 없습니다.

## 4. 권한별 사용 사례 문구 (복붙)

**instagram_content_publish**
> 사용자가 우리 도구에서 작성·승인한 이미지와 캡션을, 사용자 본인의 인스타그램 비즈니스 계정에
> 발행하기 위해 사용합니다. 발행은 항상 사용자의 명시적 승인 후에만 이뤄집니다.

**pages_manage_posts**
> 사용자가 자신의 페이스북 페이지에 본인 콘텐츠를 발행하기 위해 사용합니다.

**instagram_basic / pages_show_list / pages_read_engagement / business_management**
> 사용자의 페이지 목록과 연결된 인스타그램 비즈니스 계정을 식별해, 어느 계정에 발행할지
> 결정하기 위해 사용합니다.

## 5. 스크린캐스트 시연 스크립트 (심사 필수 영상)
심사관이 "실제로 이렇게 쓰인다"를 봐야 한다. 아래 순서로 화면 녹화:
1. 도구에서 **"인스타 연결"** 실행 → Meta 로그인 화면 → 로그인·권한 동의
2. 연결 완료 표시(계정 식별)
3. 게시물 작성(이미지+캡션) → **미리보기 → 승인**
4. 실제 인스타 비즈니스 계정에 게시물이 올라간 화면 확인
5. Meta 설정에서 **연결 해제** 동작까지 보여주기
> 1080p, 자막/내레이션으로 각 권한이 어디서 쓰이는지 짚어줄 것.

## 6. 제출
- 앱을 **라이브 모드**로 전환
- App Review → 권한별로 위 문구·영상 첨부 → 제출
- 통상 며칠~2주. 반려 시 사유의 "부족한 권한 근거/영상"을 보완해 재제출.

## 7. 통과 후
- 사용자는 `.env` 에 `META_BROKER_URL={BROKER}` 만 넣으면 **원클릭 연결**(앱 생성 불필요).
- 비즈 계정 전환만 하면 끝. (docs/META_SETUP.md 의 "원클릭 모드" 참조)
