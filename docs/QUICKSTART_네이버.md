# 네이버 블로그 자동화 빠른 시작 (P0)

계정 연결이 로그인 하나뿐이라, 가장 빠르게 가치를 보는 코어입니다. 약 10분.

## 준비물
- [Claude Desktop](https://claude.ai/download) 또는 Claude Code
- 네이버 블로그 (아이디만 있으면 됨 — 사업자 서류·전환 불필요)

## 1단계 — 설치
```bash
cd naver-marketing-mcp
python -m venv .venv && source .venv/bin/activate
pip install -e .
playwright install chromium
claude mcp add naver-marketing -- python -m naver_marketing_mcp
```
그리고 `policy.example.yaml` 을 `policy.yaml` 로 복사해 `naver.blog_id` 를 채웁니다.

## 2단계 — 브랜드 보이스 (제일 중요)
Claude에게: `브랜드 보이스 인터뷰 시작해줘`
→ 말투·금칙어를 묻고, 예전에 쓴 글 2~3개를 붙여넣으면 사장님 문체를 학습합니다.

## 3단계 — 네이버 로그인 (1회)
Claude에게: `네이버 로그인해줘`
→ 진짜 크롬 창이 뜹니다. **직접 로그인**하면 세션이 저장됩니다(비밀번호는 저장 안 함).

## 4단계 — 글 생성 → 발행
```
우리 [상품] 소개 블로그 글 써줘
```
→ 제목·본문(+이미지)이 사장님 말투로 생성됩니다. 마음에 들면 `발행해줘`.
> 기본은 **미리보기 → 승인 후 발행**. 하루 게시 상한과 사람 같은 지연이 자동 적용됩니다.

## 5단계 — 예약·무인화 (선택)
```
이 글 내일 아침 9시에 예약해줘
```
→ 예약 큐에 담기고, 스케줄러(러너)가 시간이 되면 발행합니다. 설정: `docs/스케줄러_배포.md`

## 안전 모드 (계정 보호)
자동 발행이 부담되면 `policy.yaml` 에서 `naver.mode: assist` 로 두세요.
그러면 발행 대신 **붙여넣기용 초안**을 만들어 줍니다 — 사장님이 네이버 글쓰기에 직접 붙여넣어 발행(가장 안전).

## 자주 묻는 것
- **계정 정지 안 되나요?** 하루 소량 + 사람처럼 시간차를 두고, 항상 승인 후 올립니다. 불안하면 위 안전 모드를 쓰세요.
- **비밀번호 안전한가요?** 로그인 세션만 사장님 컴퓨터 안에 저장하고, 비밀번호는 저장하지 않습니다.
