# 터미널 없이 설치하기 (Claude 데스크톱 앱)

터미널이 익숙하지 않다면 이 방법이 가장 쉽습니다. **파일 하나를 더블클릭**하면 끝입니다.

## 준비물

- **Claude 데스크톱 앱** (Mac 또는 Windows)
- 내 OS에 맞는 파일 하나:
  - **맥**(애플 실리콘과 인텔 모두): `smb-marketing-naver-mac.mcpb`
  - **윈도우**(64비트): `smb-marketing-naver-win.mcpb`

파이썬이나 uv 같은 건 **따로 안 깔아도 됩니다.** 번들 안에 들어 있어요.

## 설치 (한 번만)

1. 내 OS에 맞는 `.mcpb` 파일을 **더블클릭**합니다(맥은 `-mac`, 윈도우는 `-win`).
   - 또는 Claude 앱 창에 파일을 **끌어다 놓기**
   - 또는 앱에서 **설정 → 확장(Extensions) → Install Extension**으로 파일 선택
2. 설치 화면이 뜨면 **네이버 블로그 아이디**를 입력합니다.
   - `blog.naver.com/` 뒤에 오는 그 아이디예요 (예: `gyfhx`)
3. **설치**를 누릅니다. 끝.

## 처음 쓸 때

Claude와 대화하는 창에서 이렇게 말하면 됩니다.

> 네이버 블로그 연결해줘

- 진짜 크롬 창이 뜨면 **직접 로그인**하세요. (비밀번호는 저장되지 않고, 로그인 상태만 내 PC에 저장됩니다.)
- 처음 한 번만 로그인하면 다음부턴 생략됩니다.

## 그 다음은 말로 시키면 됩니다

> 우리 가게 신메뉴 소개글, 네이버 블로그에 감성 있게 써줘. 사진은 바탕화면 menu.jpg 넣고.

> 이 글 내일 아침 9시에 예약 발행해줘

발행 전에는 항상 **미리보기**로 먼저 보여주고, "응 발행해줘" 해야 실제로 올라갑니다.

## 잘 안 될 때

- **"확장이 시작되지 않았어요" 비슷한 오류**: 첫 실행 때 필요한 프로그램을 받느라 시간이 걸려서 그럴 수 있어요. 잠시 뒤 Claude 앱을 껐다 켜 보세요.
- **로그인이 자꾸 풀려요**: 네이버 세션은 며칠이면 만료됩니다. "네이버 다시 연결해줘" 하면 됩니다.
- **화면이 이상해요**: "네이버 화면 점검해줘" 라고 하면 로그인 문제인지 네이버 화면이 바뀐 건지 알려줍니다.
