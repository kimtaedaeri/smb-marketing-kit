# 사장님용 빠른 시작 (코딩 몰라도 됩니다)

이 가이드는 5단계, 약 30분입니다. 막히면 Claude에게 그대로 물어보세요.

## 준비물
- 컴퓨터(맥/윈도우) + [Claude Desktop](https://claude.ai/download) 설치
- 네이버 아이디(블로그), 인스타그램 계정
- (선택) 네이버 검색광고 계정 — 파워링크 유료광고 자동화용

## 1단계 — 이 키트 받기
Claude Desktop 을 열고 이렇게 말하세요:
```
github.com/kimtaedaeri/smb-marketing-kit 를 내 컴퓨터에 받아서 셋업 마법사 실행해줘
```
Claude가 내려받고 다음 단계로 안내합니다.

## 2단계 — 브랜드 보이스 만들기 (제일 중요)
```
브랜드 보이스 인터뷰 시작해줘
```
Claude가 업종·말투·금칙어를 묻고, 사장님이 예전에 쓴 글 2~3개를 붙여넣으면
**사장님 문체를 학습**합니다. → `기계가 쓴 느낌`을 없애는 핵심 단계입니다.

## 3단계 — 도구 연결
```
연결 가이드대로 도와줘
```
- **Higgsfield**(이미지·영상 생성) — 링크 클릭해 로그인 한 번
- **Blotato**(인스타·링크드인 등 게시) — 계정 연결 한 번
- **네이버**(블로그) — `네이버 로그인 창 띄워줘` → 직접 로그인(비밀번호는 저장 안 됨)

## 4단계 — 첫 콘텐츠 (게시 전 미리보기)
```
우리 [상품] 카루셀 만들어서 인스타·네이버블로그 초안 보여줘
```
Claude가 이미지 + 사장님 말투 글을 만들어 **미리보기**합니다.
마음에 들면 `이대로 게시해줘`, 고칠 게 있으면 그냥 말하면 됩니다.
> 네이버는 항상 **미리보기 → 승인 후 게시**입니다(계정 보호).

## 5단계 — 루틴 (원할 때)
```
매주 월요일 아침 8시에 이번 주 콘텐츠 7개 만들어서 예약해줘
```

---

### 자주 묻는 것
- **계정 정지 안 되나요?** 하루 게시 수 상한 + 사람처럼 시간차를 두고, 네이버는 승인 후에만 올립니다. 본인 계정으로 본인 가게를 홍보하는 정상 사용입니다.
- **비밀번호 안전한가요?** 네이버 비밀번호는 저장하지 않고, 로그인 세션만 사장님 컴퓨터 안에만 둡니다.
- **돈 드나요?** 이 키트는 무료입니다. Higgsfield·Blotato는 각자 유료 요금이 있습니다. 네이버 파워링크는 사장님 광고예산입니다.
