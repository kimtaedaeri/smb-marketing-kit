# 인스타그램 연결 가이드 (페이스북 페이지 없이)

인스타에 자동 게시하려면 **인스타 전용 액세스 토큰**(`IGAA…`로 시작) 하나가 필요합니다.
아래는 실제로 검증된 순서예요. **페이스북 페이지는 필요 없습니다.**

> 💡 이 과정은 **개발/테스트용 수동 방법**입니다. 나중에 정식 오픈되면 사장님은 "인스타 연결" 버튼만
> 누르면 되고, 아래는 안 하셔도 됩니다(우리 브로커가 대신 처리). 지금은 검증을 위한 1회 셋업이에요.

## 사전 준비
- 인스타를 **프로페셔널(크리에이터/비즈니스)** 계정으로 전환 (무료·즉시, 인스타 앱 → 설정 → 계정 유형 및 도구)
- 계정을 **공개**로

## 1. Meta 앱 만들기 + Instagram 붙이기
1. https://developers.facebook.com → 로그인 → **앱 만들기** → 앱 이름 입력
2. 이용 사례에서 **콘텐츠 관리 → "Instagram에서 메시지 및 콘텐츠 관리"** 선택
   (이미 앱이 있으면 오른쪽 위 **"이용 사례 추가"** 로 나중에 붙여도 됩니다)
3. 대시보드에서 **Instagram** 설정으로 들어가 **"Instagram 비즈니스 로그인"** 방식을 씁니다
   (❗ "Facebook 로그인" 아님 — 그건 페이지가 필요해요)

## 2. 게시 권한 추가 (안 하면 못 올림)
- Instagram 설정의 권한 목록에 **`instagram_business_content_publish`** 를 추가하세요.
  (기본은 basic/comments/messages만 있어서 게시 권한이 빠져 있습니다)

## 3. 내 인스타를 "테스터"로 등록 ⚠️ 가장 많이 막히는 곳
개발 모드에선 앱에 등록된 계정만 토큰을 만들 수 있어요. **두 단계 모두** 해야 합니다:
1. **대시보드**: 왼쪽 **앱 역할 → 역할** → **Instagram 테스터**에 본인 인스타 아이디 추가
2. **인스타그램 앱**: 설정 및 개인정보 → **웹사이트 권한(앱 및 웹사이트) → 테스터 초대 → 수락**

> 이걸 안 하면 토큰 생성 때 **"개발자 역할 권한이 부족합니다"** 에러가 납니다.

## 4. 액세스 토큰 생성
- Instagram 설정 페이지 → **"액세스 토큰 생성"** → **Instagram 계정 추가**
- 팝업에서 **인스타그램으로 로그인**(페이스북 아님) → **허용** → **토큰 생성**
- 나온 토큰은 **`IGAA…`로 시작**합니다. 이게 맞는 토큰이에요.

## 5. 연결
Claude에게: `이 인스타 토큰으로 연결해줘: IGAA...`
→ 계정을 확인하고 저장합니다. 이후 `instagram_publish` 로 게시할 수 있어요.

## 헷갈리기 쉬운 함정 (실제로 겪은 것)

| 증상 | 원인 · 해결 |
| --- | --- |
| 토큰이 **`EAG…`** 로 시작 | 그건 **페이스북 토큰**(페이지 필요). 우리가 원하는 건 **`IGAA…`**(4단계 그 위치에서 생성) |
| **"개발자 역할 권한이 부족합니다"** | 인스타를 테스터로 등록 안 함 → **3단계**(대시보드 등록 + 인스타 앱에서 초대 수락) |
| 권한 목록에 **instagram 으로 시작하는 게 없음** | 앱에 Instagram 이용 사례가 안 붙음 → **1단계**로 Instagram 추가 |
| 페이지가 0개라 인스타가 안 잡힘 | Facebook 로그인 방식이라 그럼 → **Instagram 비즈니스 로그인**(IGAA) 방식으로 |
| 게시가 거부됨 | 이미지는 **공개 URL**이어야 하고 JPG 권장. 계정은 **공개·프로페셔널**이어야 함 |

## 참고
- 이 토큰은 60일 후 만료됩니다(추후 자동 갱신).
- 페이스북 페이지 게시는 별도(페이지를 쓰는 경우만).
- **스레드(Threads)**: 위와 **똑같은 방식**으로 됩니다 — Threads 이용 사례 → `threads_content_publish` 권한 → 테스터 → "액세스 토큰 생성"(토큰은 `TH…`로 시작) → `set_threads_token`. **텍스트만으로도 게시** 가능(이미지 URL 불필요). 단 인스타와 별개 API라 **동시 게시는 안 됨**.
